# Stack Dash Claude Code Starter

This package contains the product/design/architecture documents and
Claude Code agent definitions for the Stack Dash mobile game.

## Start

1.  Extract this folder into a new Git repository.
2.  Open the repository in Claude Code.
3.  Tell Claude: **Read `MASTER_PROMPT.md` and execute it.**
4.  Let M0 finish and pass QA before approving M1.

The actual React Native/Expo application is intentionally not generated
here; Claude Code should bootstrap it during M0 according to the
architecture and acceptance criteria.
